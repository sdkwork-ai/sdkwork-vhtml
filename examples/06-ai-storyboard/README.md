# AI storyboard pipeline

An offline, deterministic AI-production example:

- a first-class storyboard with cover/push-in shots, directions and statuses;
- `image` cover generated by the `procedural` provider;
- `video` shot depends on the cover as `first-frame`;
- `music` bed and `sfx` whoosh on audio lanes;
- the `gen:` dependency graph runs `cover` before `shot`;
- one `vhtml generate` materialises all assets, then export.

Open it in Studio and use the **Storyboard** tab to add, edit, duplicate,
reorder (drag or ↑/↓) and delete shots without changing timeline timing.

```bash
pnpm --filter @sdkwork/vhtml-example-06-ai-storyboard build
pnpm --filter @sdkwork/vhtml-example-06-ai-storyboard generate
pnpm --filter @sdkwork/vhtml-example-06-ai-storyboard export
```

To use real models, change `provider: 'procedural'` to `'http'` and set
`VHTML_PROVIDER_URL` / `VHTML_PROVIDER_TOKEN`. The `direction` blocks are
provider-neutral; vendor-specific options belong in `params`.
